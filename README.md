# DEPO LOT TAKİP

Artikel → LOT lookup. Load a Google Sheet or an Excel/CSV file, then search. Works offline in the browser.

Live: https://omerakgoz34.github.io/lot-tracker/

## Build

```bash
pnpm install
pnpm run build:portable
```

GitHub Pages builds from source on every push to `main`. Hashed files in `public/` are generated output and are not committed.
